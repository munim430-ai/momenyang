# KLCC — Korean Language & Consulting Center

A responsive, zero-build landing page for KLCC. The site is built with plain HTML, CSS, and JavaScript and is ready to deploy as a static project on Vercel.

## Local preview

Open `index.html` directly, or serve the folder with any static file server.

```powershell
npx serve .
```

## Deploy on Vercel

1. Import this GitHub repository into Vercel.
2. Leave the framework preset as **Other**.
3. Keep the build command and output directory empty.
4. Deploy.

The root `index.html` is served automatically. No environment variables or package installation are required.

## Project structure

```text
.
├── assets/       # KLCC logo, founder portrait, and gallery imagery
├── index.html    # Page content and semantic structure
├── styles.css    # Responsive design system and component styles
├── script.js     # Mobile menu, animations, validation, WhatsApp handoff
└── vercel.json   # Clean URL configuration
```
